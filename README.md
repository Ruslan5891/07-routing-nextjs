# NoteHub (Next.js Routing)

Продовження проєкту `06-notehub-nextjs`: поглиблена маршрутизація в Next.js App
Router — сторінка Not found, фільтрація нотаток за тегами через паралельні та
catch-all маршрути, модальне вікно з деталями нотатки через перехоплення маршрутів.

## Маршрути

| Маршрут                 | Опис                                                                |
| ----------------------- | ------------------------------------------------------------------- |
| `/`                     | Головна сторінка із загальною інформацією про застосунок            |
| `/notes/filter/all`     | Усі нотатки: пошук за ключовим словом, пагінація, створення нотатки |
| `/notes/filter/{tag}`   | Нотатки, відфільтровані за тегом (`Todo`, `Work`, `Personal`, …)    |
| `/notes/[id]`           | Сторінка деталей однієї нотатки                                     |
| будь-який інший маршрут | Сторінка `404 - Page not found`                                     |

Сторінки нотаток — SSR: дані завантажуються на сервері через `fetchQuery` і
передаються на клієнт через `HydrationBoundary` (гідратація кешу TanStack Query).

### Фільтрація за тегом (паралельні маршрути)

`app/notes/filter/layout.tsx` рендерить два слоти: `@sidebar` з меню тегів і
`children` зі списком нотаток (`[...slug]` — catch-all маршрут). Під час зміни
тега перемальовується лише область нотаток, меню лишається змонтованим.

Тег `all` — службовий: у запит до бекенда він не потрапляє, бо API повертає всі
нотатки саме за відсутності параметра `tag`. Перелік тегів описано в коді
(`NOTE_TAGS` у `types/note.ts`), бо бекенд не має маршруту для їх отримання.

### Модалка з деталями (перехоплення маршрутів)

`app/@modal/(.)notes/[id]/page.tsx` перехоплює маршрут `/notes/[id]` під час
клієнтської навігації: нотатка відкривається в `Modal` поверх списку, а сама
сторінка лишається на фоні. Закриття (кнопка `Back`, бекдроп, `Escape`) —
це `router.back()`, тобто повернення на маршрут, з якого модалку відкрили.
Під час прямого переходу за посиланням або перезавантаження перехоплення не
відбувається і рендериться повноцінна сторінка `app/notes/[id]/page.tsx`.

## Стек

- Next.js 16 (App Router) + TypeScript
- TanStack Query (React Query) — стан запитів у CSR-компонентах
- axios — HTTP-запити
- Formik + Yup — форма створення нотатки
- CSS Modules — стилізація
- Prettier — форматування коду

## Структура

```
app/
  not-found.tsx                     сторінка 404
  @modal/
    default.tsx                     порожній слот модалки
    (.)notes/[id]/                  перехоплений маршрут: NotePreview у модалці
  notes/
    [id]/                           повна сторінка деталей нотатки
    filter/
      layout.tsx                    layout із паралельними слотами
      @sidebar/default.tsx          SidebarNotes — меню фільтрів за тегами
      [...slug]/                    catch-all маршрут зі списком нотаток
components/                         компоненти, не прив'язані до маршруту (тека на компонент)
lib/api/                            axios-інстанс і функції роботи з NoteHub API
types/note.ts                       загальні типи, інтерфейси та перелік тегів
```

## Запуск

1. Встановіть залежності:

   ```bash
   npm install
   ```

2. Створіть файл `.env.local` за зразком `.env.example` і вкажіть свій токен
   з [NoteHub API](https://notehub-public.goit.study/api/docs):

   ```bash
   NEXT_PUBLIC_NOTEHUB_TOKEN=your_personal_token
   ```

3. Запустіть дев-сервер:

   ```bash
   npm run dev
   ```

Відкрийте [http://localhost:3000](http://localhost:3000).

## Деплой

Проєкт розгортається на [Vercel](https://vercel.com). У налаштуваннях проєкту
на Vercel потрібно додати змінну оточення `NEXT_PUBLIC_NOTEHUB_TOKEN`.
